Selected upstream file: src/stepper-motor-element.ts (compiled ESM module).
AE imports the original visual custom element and wraps it in a React Flow
hardware node. AE supplies its own catalog, draft state, labels, ports and wiring
validation. The upstream package is not a circuit simulator or a robot driver.

The generic motor drawing is illustrative. It does not establish physical wire
order, dimensions, ratings, board compatibility or successful hardware tests.
The Sophicar board, STEP/DIR driver and BusLinker/HX nodes use AE's separately
defined catalog; no generic ESP32 or PWM-servo pinout replaces those devices.
